# plugin-translators Changelog

## [Unreleased]

## [1.0.0]
### Added
- Multi-provider support (Google Translate API and LibreTranslate).
- Keyboard shortcut `Alt+T` / `Option+T` to trigger translation on `strings.xml`.
- Dedicated "Android String Translator" menu in the Tools topbar.
- Searchable language selection dialog with 100+ languages.
- Support for protecting Android string placeholders (%s, %1$s, etc.).
- Settings page for API key and provider configuration.
- Background task processing for translation flow.
